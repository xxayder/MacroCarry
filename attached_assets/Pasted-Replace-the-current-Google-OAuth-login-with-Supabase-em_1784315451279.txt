3. Username rules
   - Username is the public MacroCarry identity.
   - Email remains the actual Supabase login credential.

   - Trim usernames.
   - Allow only letters, numbers, and underscores.
   - Require 3–24 characters.
   - Enforce case-insensitive uniqueness.

4. Supabase authentication
   - Sign up with supabase.auth.signUp().
   - Include username in options.data during signup.
   - Sign in with supabase.auth.signInWithPassword().
   - Preserve Supabase session persistence.
   - Preserve sign out.
   - Do not call signInWithOAuth anywhere in the active login path.
   - Do not use WebBrowser, AuthSession, redirectTo, PKCE callback processing, or mobile:// for email/password login.

5. Existing authentication code
   - Remove the Google button from the visible login screen.
   - Remove the Expo Go Google-login warning.
   - Remove signInWithGoogle from the active AuthContext API.
   - Remove Google OAuth loading and callback logic from the active execution path.
   - Do not delete dependencies until confirming they are unused elsewhere.

6. Profile storage
   - Inspect the existing Supabase profiles table, migrations, and profile-loading code before changing anything.
   - Reuse the existing profiles table if present.
   - Add a username column only if one does not already exist.
   - Preserve all existing profile fields and sharing functionality.
   - Do not overwrite or delete existing users.
   - Existing users without a username may remain nullable and should be prompted to choose one later.
   - New registrations must provide a username.
   - Use a case-insensitive unique database constraint or index.

7. Profile creation
   - Pass the username through auth user metadata during signUp.
   - Use the project’s existing profile-creation mechanism if one exists.
   - If none exists, create an idempotent Supabase SQL migration that creates the profile safely from the new auth user.
   - Follow existing RLS policies and do not weaken database access.
   - If database access is unavailable from Replit, create the migration file but do not pretend it was applied.

     “Check your email to confirm your account, then return and sign in.”

   - Do not disable email confirmation automatically.

   - invalid email or password

   - weak password
   - invalid username

   - email confirmation required
